# Employee & Payroll Management System

This is a simple Python-based Employee and Payroll Management System. It runs in the terminal and helps manage employee details, attendance, overtime, and monthly salary.

## Features

* Add new employees
* View employee details
* Update employee information
* Remove employees
* Mark daily attendance
* View monthly attendance
* Calculate and display monthly payslips
* Calculate overtime and attendance deductions

## Technologies Used

* Python 3
* Lists
* Dictionaries
* Functions
* Loops
* Conditional statements

No external libraries are required.

## How to Run

1. Install Python 3.
2. Save the program as `employee_payroll.py`.
3. Open the terminal in the project folder.
4. Run:

```bash
python employee_payroll.py
```

## Payroll

The program calculates salary using the basic salary, HRA, travel allowance, overtime, PF, and absence deductions.

## Note

The data is stored only while the program is running. Once the program is closed, the data is lost.
